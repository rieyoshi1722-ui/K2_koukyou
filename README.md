# K2_koukyou

高校2年「公共」の穴埋めドリル(スマホ向けの1枚のWebページ)。
第3章「公共的な空間における基本原理」(プリント12ページ分)が元になっています。

## 中身
- 章ごとの穴埋め(7章、53問)。出すたびに穴の場所が変わる
- 条文の番号あて(35問)。「番号が穴」と「内容が穴」がランダムで入れ替わる
- 判例マッチング(8件)。タップで事件名と内容を結ぶ
- 復習フォルダ。まちがえた問題がたまり、「できた」で外れる

## ファイル
- `src/data1.js`〜`data4.js` 穴埋め問題(`{{答え}}` が穴の候補)
- `src/data5.js` 条文の番号あて、判例マッチング
- `src/app.js` 画面と動き
- `src/head.html` 見た目(CSS)
- `build.sh` 上のファイルを `page.html` にまとめる
- `tests/` 問題データの形式チェックと動作テスト

## 作り方
```
./build.sh
node tests/check.js
node tests/test.js
```

## 注意
10〜12ページは手書きの答えがなく、教科書の知識で答えを入れた問題があります(画面に「先生のノートと見比べてください」と出ます)。
